# Khouta: Your Financial Compass

قم ببناء تطبيق هاتف ذكي للتقنية المالية (FinTech) باللغة العربية باسم "خُطى" (Khouta) متوافق تماماً مع الواجهات المرفقة لرحلة إنشاء الحساب (Onboarding Journey). يجب تعريب الواجهات بالكامل واستخدام نفس الهوية البصرية (اللون الأخضر الداكن المالي، الأبيض، والخطوط العربية الحديثة والواضحة). تتكون رحلة إنشاء الحساب من الخطوات التفاعلية التالية (مع مؤشر خطوات علوي يربط بينها): 1. شاشة تسجيل الدخول / البدء: تطابق الشاشة الأولى بشعار "خُطى" مع حقول رقم الجوال/البريد، كلمة المرور، زر "تسجيل الدخول"، وخيار "إنشاء حساب جديد". 2. الخطوة (1) - إنشاء الحساب (البيانات الأساسية): حقول لإدخال الاسم الكامل، رقم الجوال، اختيار المدينة، وأزرار اختيار الفئة (طالب، موظف، صاحب عمل، أخرى). 3. الخطوة (2) - البيانات المالية: - قسم (مصدر دخلك) بأزرار تفاعلية (راتب شهري، مكافأة، عمل حر، أخرى) مع حقل لتحديد الدخل الشهري. - قسم (المصاريف الثابتة شهرياً) بحقول مخصصة (السكن، المواصلات، الإنترنت، أخرى) مع إمكانية "إضافة مصروف آخر". - قسم (المصاريف المتغيرة) بأزرار تفاعلية (المطاعم، التسوق، الترفيه، أخرى) مع مبالغها. - قسم (هدف الادخار) بحقول: مبلغ الادخار الحالي (اختياري) والمبلغ الذي ترغب بالوصول له. 4. الخطوة (3) - حدد هدفك المالي: شبكة أزرار لاختيار نوع الهدف (شراء سيارة، لابتوب، سفر، زواج، تعليم، منزل، طوارئ، هدف مخصص). عند تحديد الهدف، تظهر بطاقة خضراء أنيقة تعرض "اسم الهدف، المبلغ المقترح، والتوفير الشهري تلقائياً" مع تحديد المدة الزمنية (3 أشهر، 6 أشهر، سنة، سنتين، +3 سنوات). 5. الخطوة (4) - إضافة بطاقة الدفع (ربط البنك): واجهة تفاعلية تحاكي ربط بطاقة "مدى mada / VISA" خضراء اللون، مع حقول (رقم البطاقة، اسم حامل البطاقة، تاريخ الانتهاء، رمز الأمان CVV) متبوعة بزر "إضافة البطاقة". 6. واجهة حركة تحميل الخطة (Plan Generation Animation): تحاكي آخر صورتين مرفقتين؛ تظهر قائمة متتالية بعلامات التحميل الدائرية وعلامات الصح الأخضر (تم): (تحليل الدخل الشهري، تحليل المصروفات، تحليل معاملات البنك، حساب أفضل ميزانية، إنشاء التقويم المالي، تجهيز المستشار الذكي)، لتنتهي بعبارة "خطتك جاهزة! ستنتقل للرئيسية تلقائياً". بمجرد اكتمال التحميل، ينقل التطبيق المحكم/المستخدم إلى "الشاشة الرئيسية للتطبيق" التي تحتوي على: سارسلها بعد هذا لان الصور امتلئت
