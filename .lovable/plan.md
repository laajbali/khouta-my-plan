# خطة تحويل تطبيق خُطى إلى مستوى تطبيقات البنوك السعودية

## 1. الطباعة والهوية النصية (Cairo + هرمية بنكية)

- استبدال خط `Tajawal` بـ **Cairo** عبر Google Fonts في `src/routes/__root.tsx` وتحديث `--font-arabic` في `src/styles.css`.
- إضافة صنف utilities للأرقام: `.font-numeric` بأوزان Semi-Bold و tabular-nums لعرض واضح للمبالغ.
- تطبيق هرمية موحّدة عبر كل الشاشات:
  - عناوين الشاشات: 22–24px / 700
  - أرقام المبالغ: 18–20px / 600 + tabular-nums
  - وصف/عناوين ثانوية: 12–14px / 400
  - تسميات شريط التنقل: 11px / 500
- إزالة الإيموجي (🚗 🤖 🎁 📊 📅 🔔 👋 💼 ♥) واستبدالها بأيقونات outlined من `lucide-react` بلون واحد (`text-primary` / `text-muted-foreground`).

## 2. تفعيل التنقل والتمرير (كل زر يعمل)

- تثبيت `BottomNav` أسفل إطار الهاتف مع `position: sticky` بحيث تبقى الشاشة الفعلية قابلة للتمرير (تعديل `PhoneFrame` و `HomeScreen`).
- ربط التبويبات الخمس بشاشاتها الحالية (موجودة) وتفعيل الأزرار الفرعية:
  - بطاقات الاختصار (المستشار، التقويم، التقارير، المكافآت) تفتح شاشات فعلية.
  - «عرض التفاصيل» يفتح صفحة تفاصيل الهدف.
  - «كشف الحساب» يفتح صفحة العمليات الكاملة.
  - «إضافة هدف» يفتح شاشة إنشاء هدف يُحفظ في قاعدة البيانات.
- إضافة نظام تنقل داخلي بسيط (state stack) داخل `HomeScreen` لدعم فتح شاشات فرعية مع زر رجوع، دون تغيير معمار الرواتر.

## 3. المستشار المالي «نور» (شات تفاعلي)

- شاشة `NoorChat` جديدة تُفتح من بطاقة «المستشار المالي».
- واجهة محادثة: فقاعات مستخدم/مساعد، مؤشر كتابة، أزرار رد سريع مثل «كم صرفت هذا الأسبوع؟»، «اقترح لي ميزانية»، «هل أستطيع شراء…؟».
- محادثة محلية بدون AI حقيقي في هذه المرحلة (ردود جاهزة سياقية). لاحقاً يمكن ربطها بـ Lovable AI Gateway إن رغبتِ.

## 4. الربط البنكي المفتوح (SAMA Open Banking)

- استبدال `Step2Financial` (إدخال يدوي) بشاشة «اربط حسابك البنكي».
- زر رئيسي كبير: «الربط عبر الحساب البنكي المفتوح (معتمد من ساما)».
- شبكة شعارات بنوك سعودية (الراجحي، الأهلي، الإنماء، الرياض، البلاد، الجزيرة) كأزرار اختيار مع مؤشر «موافقة ساما» وشارة أمان.
- بعد الاختيار: محاكاة سريعة لجلب البيانات (progress) ثم حفظ البنك المختار في Supabase.

## 5. تدخّل الإنفاق الذكي (Shein Intercept)

- زر تجريبي «محاكاة عملية SHEIN» في شاشة الرئيسية (قسم مطوّر) لعرض التدفق.
- Modal مركزي بخلفية معتّمة (Dialog من shadcn) بعنوان **«لحظة يا سارة!»**، مع سبب التدخل («هذه العملية ستتجاوز ميزانية التسوق لهذا الشهر»).
- زران:
  - Primary أخضر كبير: «إلغاء الطلب وتوفير 240 ر.س».
  - نص رمادي صغير ثانوي فقط: «متابعة الشراء رغم ذلك».
- تسجيل قرار المستخدم في جدول `intercept_events`.

## 6. قاعدة البيانات (Lovable Cloud / Supabase)

سؤال أساسي قبل البدء: **هل نحتاج ملفات مستخدمين (profiles) أم يكفي `auth.users`؟** الاقتراح: نعم — لتخزين الاسم والراتب والبنك المختار.

الجداول المقترحة:
- `profiles(id, full_name, monthly_income, linked_bank, created_at)` — FK إلى `auth.users` مع سياسات RLS تسمح للمستخدم بقراءة/تحديث ملفه فقط.
- `savings_goals(id, user_id, title, target_amount, saved_amount, deadline, icon, created_at)` — RLS يخص المالك.
- `transactions(id, user_id, merchant, amount, category, occurred_at)` — يُعبّأ بمعاملات محاكاة عند الربط البنكي.
- `intercept_events(id, user_id, merchant, amount, decision, created_at)` — لتتبع قرارات تدخّل الإنفاق.

المصادقة: بريد + كلمة مرور، مع إمكانية إضافة Google لاحقاً. شاشة `LoginScreen` و `Step1Account` تُربط بـ `supabase.auth`.

## القطع التقنية (Technical Details)

- Bottom nav: `position: sticky; bottom: 0` داخل `PhoneFrame` وجعل الحاوية الداخلية `overflow-y-auto` مع `flex-1` لضمان تمرير المحتوى وثبات الشريط.
- كل الشاشات الفرعية عبر state داخلي: `type Route = "home" | "goal-detail" | "noor" | "statement" | "new-goal"` في `HomeScreen`.
- shadcn `Dialog` لـ Shein modal، `ScrollArea` لقائمة العمليات.
- استخدام tokens: `--font-arabic: "Cairo"` + `--font-numeric: "IBM Plex Sans Arabic"` (اختياري) — الأرقام العربية-اللاتينية بـ `font-variant-numeric: tabular-nums`.
- كل استعلامات Supabase عبر `createServerFn` مع `requireSupabaseAuth`؛ الواجهة تستخدم TanStack Query.

5. محادثة «نور» بردود سياقية جاهزة.
